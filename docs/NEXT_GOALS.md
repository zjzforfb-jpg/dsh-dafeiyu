# 大肥鱼后续目标清单

## G5：策略选择与效率优化

### 目标

让大肥鱼能够根据设备、页面状态和历史结果，选择成功率更高的操作策略，同时保持权限和合规边界不变。

### 范围

- 统计不同定位策略的成功率。
- 统计平均耗时、重试次数和未知回执率。
- 根据环境选择策略：UI 节点、文本定位、坐标回退或重新观察。
- 先实现可解释的规则排序，再引入 Contextual Bandit。
- 暂不进行在线模型训练。

### 交付物

- `strategy_trials` 数据表。
- 策略评分模块。
- 按设备、App、Activity 和页面状态的策略选择器。
- 策略试验回执和回滚记录。
- 策略评测脚本。

当前进度：策略试验表、统计和可解释选择器已完成；抖音评论和回复流程已接入策略试验记录。当前仍使用安全的默认 `uia_smart` 路径，待积累真实验证数据后再启用策略比较。

### 验收标准

- 每次策略选择都有原因和证据。
- 成功率、耗时和重试次数可查询。
- 未验证动作不会因为策略优化而自动放行。
- 新策略失败可以立即回退到上一版本。
- 误点击率和重复发送率不能高于基线。

## G6：统一认知中枢

### 目标

让桌面、微信、QQ 和手机动作统一经过认知中枢，而不是由各渠道独立决定流程。

### 范围

- 统一任务入口。
- 统一环境观察。
- 统一记忆调度。
- 统一技能选择。
- 统一策略和权限检查。
- 统一真实回执。
- 统一失败恢复。

### 交付物

- `Cognition Kernel` 控制器。
- 上下文构建器。
- 计划和步骤状态机。
- Policy Engine 接口。
- Action Engine 适配器接口。
- Evaluator 结果评价接口。

### 验收标准

- 同一任务不能被多个渠道重复执行。
- 每一步动作都有前置条件和后置验证。
- 模型中断、服务重启和手机断开可以安全恢复。
- 认知中枢不能绕过任务、权限或回执系统。

## G7：长期记忆事实提炼

### 目标

将每日记忆摘要中的重要内容提炼为可审计的事实候选，避免把所有日常对话直接永久化。

### 交付物

- 每日摘要事实候选提取器。
- 事实冲突检测器。
- `supersedes_id` 版本链。
- 候选、确认、过期和废弃状态。
- 爸爸确认和纠正接口。

### 验收标准

- 单次推断不能直接成为确认事实。
- 新事实不会无记录覆盖旧事实。
- 删除后的事实不能从摘要和缓存中召回。
- 每条事实都能追溯到原始事件。

## G8：人格一致性与成长

### 目标

让大肥鱼保持稳定核心人格，同时允许知识、偏好、技能和反思逐步成长。

### 分层

- `Identity Core`：身份、性格、称呼、价值观和边界。
- `Dynamic State`：当前情绪、精力和关注点。
- `Acquired Traits`：经过证据积累形成的偏好、知识和技能。

### 验收标准

- 一次失败不会改变核心人格。
- 偏好变化必须有来源和时间依据。
- 微信、QQ、桌面表达风格保持一致。
- 人格配置修改可审计、可恢复。

## G9：自动化性能优化

### 目标

降低手机感知和抖音操作延迟，但不牺牲动作验证和安全性。

### 交付物

- ADB、截图、UI 树、OCR、决策和动作的分阶段计时。
- 局部截图和局部 OCR。
- AccessibilityService 事件接入评估。
- 规则快路径和云端长尾路径。
- p50、p95、p99 性能报告。

### 验收标准

- 感知 p95 小于150ms。
- 规则决策 p95 小于20ms。
- 普通动作端到端 p95 小于500ms。
- 动作成功率高于98%。
- 未验证动作继续率为0。

## G10：发布与长期稳定性

### 目标

让所有已启用能力经过稳定性观察、数据备份、回滚和发布门槛检查。

### 验收标准

- 全部测试通过。
- 7天稳定性观察达标。
- 没有未处理的 unknown/dispatched 外部动作。
- 数据库迁移可回滚。
- 敏感信息扫描通过。
- 能力矩阵与真实回执一致。

## 执行顺序

```text
G5 策略选择
→ G6 认知中枢
→ G7 事实提炼
→ G8 人格成长
→ G9 性能优化
→ G10 稳定发布
```

每个目标完成后都必须留下：代码、测试、运行记录、文档和验收结论。没有真实回执或评测数据的能力，只能标记为候选或实验状态。
