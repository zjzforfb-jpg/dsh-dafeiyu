# 抖音界面速查（爸爸教的，2026-11-14）

> 目的：碰到这些界面时先认位置，再动手。规则来自爸爸的现场教学 + 我们踩过的坑。

## 1. 互动消息（消息 → 互动消息）

| 元素 | 含义 | 我们要做什么 |
| --- | --- | --- |
| 「回复评论」按钮（评论行左侧） | 回到那条评论去回复 | 要回 |
| 「赞」按钮（评论行右侧的 ♡） | 给这条评论点赞 | 要赞 |
| 红色小心心（赞了你的图文那一行，头像右下角） | 回赞对方 | 要赞；小心心变成灰色小飞机时**不要点**（那是私信） |
| 灰色小飞机 / 箭头 | 私信或跳转主页 | 不点 |

判断「有没有新互动」：看这一行左侧有没有小红点；没有红点 = 已经处理过。

## 2. 个人主页（右下角「我」）

- 顶部：头像、昵称、抖音号、获赞、互关、关注、粉丝；
- 作品网格：**越新越靠前**；
- 作品格子里点进去 = 作品详情。

## 3. 作品详情（点开自己的作品）

| 位置 | 含义 |
| --- | --- |
| 顶部「评论 / 赞 / 收藏 / 浏览」 | 点「评论」进评论面板；点「赞」看点赞名单 |
| 右侧竖栏 ♡ | 给自己作品点赞（不需要） |
| 右侧竖栏 ♡ 下面的气泡 | 打开/关闭评论面板 |
| 评论面板每行右侧的 ♡ | 给这条评论点赞 |
| 评论面板「回复」 | 回复这条评论 |
| 底部「有什么想法，展开说说」 | 发一条评论（可带图/表情） |

> 注意：截图里评论行最右侧那个「决裂样式」的小星星（不喜欢/更多）**不要点**，容易误触举报。

## 4. 我们踩过的坑

1. 主页作品是自绘列表：必须先进「用户」Tab，再点卡片；点文字节点无效时点头像。
2. 搜索提交要点「搜索」按钮，ADBKeyboard 下回车不可靠。
3. 评论框会残留上次草稿，发送前先清空。
4. 回赞只点「红心」；红心变灰的小飞机是私信，别点。
