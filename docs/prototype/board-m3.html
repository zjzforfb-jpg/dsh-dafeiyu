模块化架构 · 加模块只改两处

前端一个注册表，后端一个数据源表；新增页面/数据源都不用碰 shell 和路由。

connect/board/
  shell.mjs        # 顶栏 + 导航 + 轮询 + 路由（不认识具体模块）
  index.mjs        # MODULES = [home, content, interact, growth, system]
  modules/
    home.mjs  content.mjs  interact.mjs  growth.mjs  system.mjs
  sections.mjs     # 分页数据源注册表（Map）
    sections/works.mjs comments.mjs hot.mjs timeline.mjs ...
  • 加一个页面：新建 modules/粉丝.mjs，在 index.mjs 的 MODULES 里加一行。
  • 加一个列表：新建 sections/snapshots.mjs，在 sections.mjs 注册一行；GET /api/board/list?section=snapshots 立即可用。
  • 卡片规范：标题+计数+右侧操作 / 行高 ≥52 / 两行文字 / tag 五色 / 统一分页。
  • 单文件 ≤400 行，超了拆子模块。
