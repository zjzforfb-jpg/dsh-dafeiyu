# 大肥鱼记忆模型

## 记忆分层

```text
daily_memory_events（每天完整流水，短期保留30天）
        ↓ 每天凌晨约01:00–02:00整理
daily_digest（当天摘要）
        ↓ 只有高价值、明确事实或共同经历才进入
长期 memories（可纠正、可删除、带来源和可信度）
```

每天来自微信、QQ、桌面和其他已接入渠道的输入/回复都会写入 `daily_memory_events`，包括渠道、会话类型、联系人、输入类型、双方文本、重要度和隐私范围。敏感字段会在写入前脱敏。QQ群事件保留在每日流水中，但 `privacy_scope=group`，不会自动写入爸爸的私人长期记忆。

长期记忆仍遵循明确保存、共同回忆、偏好和系统反思规则；每日流水不会全部塞进长期模型上下文。这样既能实现“今天发生过什么”的连续感，又能避免噪声、群聊内容和敏感信息永久化。

## 当前实现

- QQ 私聊/群聊：每次成功处理的消息记录到每日流水。
- 微信 iLink：每次成功回复记录到每日流水；语音使用已转写文字，并保留 `input_kind=voice`。
- 桌面聊天：原有长期记忆和对话记录继续运行，后续应接入同一 `recordDailyExchange` 接口。
- 每天凌晨约 01:00–02:00，Connect 调用 `scripts/memory-digest.mjs`，将活动流水和每日流水整理为 2–4 句当天摘要，写入 `daily_digest`。
- 整合按北京时间前一天日期运行，成功后才把日期写入 `runtime/connect/memory-digest.json`；模型或服务失败不会标记成功，下一次 10 分钟调度会重试。摘要内容通过固定日期和 `recordActivity` 去重，重复运行不会生成重复长期记忆。
- 每日原始流水保留30天，长期摘要按原有记忆规则保留。

该方案不会把每条普通聊天直接变成永久人格事实；“看见/说过”与“长期记住”被明确分开。
