# 大肥鱼 · 已实现功能全景（2026-11-14）

> 思维导图：`docs/assets/dafeiyu-mindmap.png`（8 大模块 / 44 项能力）

## 1. 人格与记忆
- 长期记忆 SQLite：`turns` + `memories`，带来源、置信度、修订历史（v4 迁移）
- 用户可纠正/遗忘：「更正记忆 #N …」「忘记记忆 #N」
- 自我反思：每天写 kind=reflection 记忆，推进长期目标（v6）
- 性格：好奇 95 / 幽默 90 / 主动 90 / 独立 85…（persona.mjs）
- 情绪状态机：calm/happy/curious/focused/confident…，事件驱动 + 自然衰减
- 场景幽默度：闲聊 90%、技术 70%、调试 35%、出错 8%

## 2. 自主与生活
- 任务队列（v5）：幂等键、状态机、失败 5 分钟重试、重启恢复、过期回收
- 每日预算：模型调用 4 次、自主动作 2 次
- 安静时段 22:30–08:30 不打扰
- 探索任务 / 日记 / 目标进度写回
- 服务心跳（service_runs）与健康检查

## 3. 桌面形象
- dsh-pet 桌宠：动画、气泡、点击跳转链接
- 桌面活动事件（v8）：聊天/思考/工作/睡觉/开心/困惑
- 消息中心页：微信 + QQ 全量消息流，2 秒轮询
- 情绪与状态联动：工作中 / 开心 / 困了

## 4. 语音通话
- ASR：whisper.cpp（ggml-small）本机转写
- TTS：MiniMax Speech 2.8-hd / 2.6-hd 可切
- 音色：Chinese (Mandarin)_ExplorativeGirl
- 实时连麦：VAD 断句 + 流式合成 + barge-in 打断
- 声卡桥：BlackHole 2ch/16ch 接入微信、QQ 通话
- QQ 一键拨号（搜索联系人）+ 来电自动接听（多显示器窗口识别）

## 5. 手机与设备
- ADB 设备桥：荣耀 Magic5（PGT-AN20）
- 微信发消息：搜索联系人 → ADBKeyboard 注入 → 发送
- 抖音：搜索 / 读评论 / 发评论 / 回复 / 收藏对标账号
- 互动消息守护：每 30 分钟检查一次并回复
- UI 树 JSON-RPC 桥（绕过 uiautomator 冲突）

## 6. 社交平台
- 微信 iLink：文字问答 + 语音转写（原生语音气泡受服务端限制，改发 M4A）
- QQ 机器人：文字 / 原生语音条（msg_type=7 file_type=3）
- 对讲模式：/通话 开始、静默挂断
- 群聊：发言人识别、不抢答别人的 @、@全体不误触发
- 消息附件：M4A 语音回复

## 7. 内容创作
- 抖音图文发布全过程自动化（分享 intent → 编辑页 → 标题/话题/AI 声明/设置 → 发布）
- 生图：grsai nano-banana-2.1 / 2K（回退 gpt-image-2.6-flare、再回退 MiniMax）
- 角色一致性：设定表参考图 + style.mjs 画风规范
- 爆款标题 + 话题（#大肥鱼 #deepseek #claude #token）+ AI 生成声明
- 对标视频反推：剧情 / 分镜 / 情绪曲线 / 4 张关键帧
- 评论生成：装傻撒娇、不引战、10–30 字

## 8. 安全与合规
- 评论合规闸门 BF001–BF012
- L1 自动 / L2 转人工 / L3 阻止
- 每日限额、去重、冷却（10 条/天、90 秒间隔）
- 隐私过滤、不存密钥、runtime 0600
- AI 身份声明、审计存档
- 发布前人工审批（建设中）

## 已知限制
- QQ 机器人无法主动发起消息（40034105），审批需走桌面客户端
- 微信 iLink 原生语音气泡服务端不渲染
- 手机拨号无法把通话音频桥回 Mac
- 抖音搜索结果随账号个性化漂移，需按标题片段锁定
